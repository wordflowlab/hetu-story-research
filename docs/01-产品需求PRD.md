# 产品需求

## 1. 背景与价值

把灵感、考据和公开观察整理为有据、可争论、可供规划引用的研究成果。 作者无需将对话中已有的信息重新填表；Agent准备完整结构，软件呈现固定成果与依据。

重复生成一次性文字会丢失来源、适用范围与返工历史。将稳定的引用校验、专业结构、查询、覆盖、导出及恢复工程化，使外部Agent集中于理解和生成；不承诺未经测量的Token节省比例。

## 2. 专业闭环

提出问题 → 固定资料 → 区分引文、观察与推断 → 比较支持与反证 → 形成带限制的结论 → 固定交接给规划或写作。

首版包括本包数据、局部维护与依赖检查、固定读取、专业投影、有界上下文、JSON／Markdown／离线HTML、同包Skill及机器／工作面接续；完整功能导航见03。没有正文也可以建立专业空方案，证据不足明确显示，不伪造结果。

## 3. 边界与质量

作品身份、正文、资料、正式设定、候选、意见、作者决定及事务归宿主。本插件只维护研究问题、来源观察、结论及其支持与反证。安装启用后复用开放SDK，不增加逐动作插件授权。

来源可定位；固定修订不漂移；专业引用不悬空；未知和未完成可区分；长文本预算和覆盖透明；历史可读；同一Codex连接可重新发现、启停与继续。题材不限定，中文／混合文本、长篇分块和原文换行需单独验证。
