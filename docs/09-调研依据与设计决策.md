# 调研依据与设计决策

固定来源、提交、许可与定向阅读范围见[来源记录](research/sources.json)。对应仓库已逐个克隆为research base，源码不作为本包运行依赖；README说明、定向源码阅读和运行证据分别记录。

采用来源分层、采集时间与交叉核对；不抓取付费正文，不以转载代替权利，不把排行等同于创作质量，不从章节标题推断已读剧情。

采用普通TypeScript领域＋React视图＋固定公共SDK；不复制上游模型渠道、内置Agent、自有正文库或私有路径。宽松开源只说明对应许可范围，素材、依赖和文稿权利另行核对；GPL参考只借功能与流程启发，本包独立实现。

跨插件协作的最小公共需要是“在当前获权作品下读取确切Owner的固定专业修订”，无须增加跨插件写权、全库授权或统一专业数据库。若宿主旧版不能完成，此需求通过公共只读合同与真实用例先验证，再确定最低宿主版本。
