# 界面与交互设计

独立工作面仅保留左上返回、方案选择、修订、刷新和“让AI处理”；宿主顶部与左侧不重复占据插件页面。页签为：研究问题、来源观察、研究结论、依据与冲突。专业内容默认以可阅读文本、依据和必要图表呈现，作者不必编辑JSON。

使用宿主共享Radix色板、连续静态渐变及轻透表面，字号12／14／20px、边框0.5px；正文与输入保持稳定纸面。普通内容以留白和细线组织，最多一个高强调主操作。图形必须有等价列表，不伪造坐标、曲线或作者评价。

加载、无方案、无专业数据、部分覆盖、来源不可用、冲突、unknown和成功分别呈现。空状态可直接交接Agent；有对象时携带固定专业引用和作者目标。技术ID和摘要收进高级详情，不替代正常内容。

依据可回读，旧稿明确版本；导出固定当前修订。高级编辑是可选入口，冲突保留输入、基线和恢复稿，关闭重开不默默丢弃；unknown保留原操作回读入口。浅暗、760／1360px、键盘焦点、换行、长标题及无横向溢出独立验收。
