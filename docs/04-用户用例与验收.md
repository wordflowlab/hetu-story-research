# 用户用例与验收

| 编号 | 场景 | 必须证明 |
| --- | --- | --- |
| B-01 | 有引文与只有标题的资料 | 分别记录观察和推断，不能伪造原文证据 |
| B-02 | 两份相互冲突的观察 | 冲突摘要包含双方，结论不可伪装为无争议事实 |
| B-03 | 没有来源的灵感 | 允许记录假设，但不标为已证实 |
| B-04 | 引文错误或UTF-8边界错误 | 拒绝保存，旧对象保持 |
| B-05 | 来源已更新 | 旧结论仍指向旧修订，更新需追加来源 |
| B-06 | 删除被结论使用的观察 | 拒绝悬空引用，先显式处理依赖 |
| B-07 | 公开市场观察与历史资料混合 | 保留来源角色和采集日期，结论有适用范围 |
| B-08 | 问题、结论交给人物或规划 | 读取固定专业引用并核对Owner、作品、修订和摘要 |
| B-09 | CAS、同键重放和响应丢失 | 保留旧修订，原键恢复，不重复写入 |
| B-10 | 同一连接安装、启停、卸载重装 | 动作和Skill动态发现，数据仍可回读 |
| B-11 | 恶意HTML、中文长段、窄窗和键盘 | 离线输出转义，工作面可读且无横向溢出 |
| B-12 | 旧版本与外部副作用 | 不因专业保存采纳正文、改设定、定稿或付费 |

单元验证不变量和专业反例，真实CLI/MCP验证所有动作、固定来源、跨作品隔离、CAS及恢复，Electron验证作者工作面、固定导出、浅暗、窄窗、键盘及重开；当前Codex会话发现独立取证。发布制品、跨平台与作者实际质量判断分别验收，不以测试数量替代。
