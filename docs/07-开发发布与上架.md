# 开发发布与上架

使用Node.js 25和npm固定依赖，构建含静态Schema校验器、后端、React工作面、Skill、功能清单及第三方许可。`vendor/sources.json`固定公共SDK与色板摘要，构建先核验；包不在安装时执行上游安装脚本。

```bash
npm ci
npm run build
npm run verify
npm run package
```

机器测试使用隔离作品。`HETU_SOURCE`指定宿主源码目录，`HETU_TEST_BIN`指定同版Core／CLI／MCP目录，`HETU_PLUGIN_MANAGER`指定同版受管插件运行器，`HETU_TEST_PACKAGE`指定最终包；正式安装验证同时指定`HETU_PACKAGED_APP`，不得混用开发与安装版证据。脚本默认值和确切版本由测试支持代码及08记录。

发布前固定源码、制品包摘要和解压目录摘要，完成安装／停用／升级／卸载／重装、旧修订及原操作恢复，核对包内Skill和可视化成果。只有用户要求发布时再创建远端仓库、提交、Tag及发行；源码生成和本地验收不等于上架。插件中心收录须按河图插件23／24的公开固定制品合同办理。

## 机器与界面测试环境

机器测试需要宿主的Node开发依赖、同版CLI／MCP／插件CLI／App Server，以及`apps/desktop/dist/plugin-manager.mjs`。源码环境先执行宿主桌面构建，再运行本包测试；作者安装包不需要源码。包内Skill不额外安装到Codex配置。

```bash
npm run test:unit
npm run test:machine
npm run test:ui
```

最终归档解压后须按公开inspect_package核对。机器、界面及正式安装的环境和摘要分别记录，不能混用证据。
